# 验证说明

## v0.5.0 Ubuntu 24.04 构建与兼容性验证（2026-11-05）

本节记录 v0.5.0 的实际检查范围。Ubuntu 24.04 的验证在隔离容器中完成；桌面音频与受控输入验证在当前 Ubuntu 26.04.1 LTS 主机完成。本轮没有连接遥控器，也没有调用收费语音接口，实物与云服务记录见下方历史章节。

### 构建、依赖与单元测试

- 使用 Ubuntu 24.04 x86_64、Python 3.12.3 构建 AppImage 和 DEB；源码 **82 项单元测试通过**。
- 审计包内 **222 个 ELF 文件**，观察到的最高动态符号需求为 **GLIBC_2.38**。发布支持基线仍定为 **glibc 2.39 / Ubuntu 24.04**，不据此宣称兼容更旧系统。
- 下方 v0.4.0 记录中的 GLIBC_2.43 要求仅适用于旧包，不适用于本次重新构建的 v0.5.0。

### Ubuntu 24.04 AppImage 与普通用户检查

- 在没有额外安装 Python、GTK 的纯净 Ubuntu 24.04 基础镜像中关闭网络，`--appimage-extract-and-run --version` 和 `--appimage-extract-and-run --self-test` 均通过。
- 使用普通用户 `tester`、临时 HOME、独立 D-Bus 与 Xvfb，并将 AppDir 设为只读：**15 项中英文界面检查**和 **5 项识别来源检查**均通过。该环境的通知栏菜单检查不代表真实桌面托盘已验证。
- 使用普通用户运行包内 SenseVoice 识别，公开 **5.592 秒**音频样例得到 **14 个字符**。模型由测试环境另行提供，发行包不包含模型。

这些检查验证了运行库、无特权启动、界面逻辑与离线推理。它们没有覆盖 Ubuntu 24.04 的实机蓝牙、真实 PipeWire 会话、GNOME/KDE 通知栏或跨应用自动输入；容器中的 Xvfb 也不等同于真实 Wayland 桌面。

### Ubuntu 24.04 DEB 安装生命周期

在已准备所需系统依赖的断网容器中完成以下检查：

- 安装 `remote-mic-linux_0.5.0_amd64.deb`，以非 root 用户运行自测，校验 desktop 文件。包声明 `fontconfig-config` 依赖，并推荐 Noto CJK / DejaVu 字体。

以上检查均通过。**跨版本升级尚未验证**；同版本重装不能代替从旧版升级的测试。

## 历史验证与复现方法

以下记录保留对应版本的实际结果；较早版本的构建环境、测试数量和依赖基线不应套用于 v0.5.0。

## 自动检查

    .venv/bin/python -m unittest discover -s tests -v

2026-11-05，v0.3.0 本机 52 项通过，覆盖 ATVV、按键释放、手势、识别队列、过期结果、有道签名及模拟通信、凭据权限、文本输入取消、焦点事件顺序和 Wayland/XWayland 判断。测试不调用真实收费接口。

## 受控跨应用验证

在已登录的 GNOME 桌面会话运行，需 GTK、AT-SPI、XWayland 和 /dev/uinput 访问权限。测试会弹出自己的独立输入窗口；等待约 8 秒，期间不要切换窗口：

    .venv/bin/python scripts/check_cross_app.py --backend x11
    .venv/bin/python scripts/check_cross_app.py --backend wayland

测试先核对目标属于自己创建的子进程，再模拟“语音开始”和“最终结果”事件。它使用固定文本，不录音，不连接遥控器或有道，不读取其他应用文本。测试设置位于临时目录。成功时输出 passed: true 和字符数 8；不自动按 Enter。

本机 0.2.1 和 0.3.0 均在独立 X11 和原生 Wayland GTK 输入框通过。0.3.0 验证时桥接窗口在后台，两个目标均收到 8 个字符。该结果验证焦点、剪贴板与虚拟按键链路，不等于所有应用兼容。

## 真实遥控器验收

1. 启动程序并连接遥控器，选择本地或已配置的有道模式。
2. 在另一个应用中点入实际要输入的文本框，保持这个窗口和输入框处于焦点。
3. 不切回桥接程序；按住遥控器语音键说话，松开后等待文字出现。
4. 确认文字只出现一次，没有自动回车或发送。
5. 另测识别期间切换到不同窗口、停止连接，确认取消输入且结果仍可复制。

先前用户已确认本地与有道均能将遥控器识别结果输入程序内安全测试框。修复版在用户日常应用中的完整遥控器验收尚待确认，应与受控窗口测试分开记录。

## 已知边界

- 仅遥控器 2 / RC001 有实物测试，2 Pro / RC003 待实测。
- 不提供无障碍字段信息的应用只能按窗口校验，不能保证发现同窗口内的字段变化。
- 焦点与密码框识别依赖应用公开的无障碍信息；无法识别所有密码框。
- 使用 Ctrl+V，终端需按 UI 设置选择 Ctrl+Shift+V。自定义粘贴快捷键或禁用粘贴的输入框可能不支持。
- GTK 剪贴板桥接在本机 X11/XWayland 程序进程中验证；其他桌面环境仍需验证。
