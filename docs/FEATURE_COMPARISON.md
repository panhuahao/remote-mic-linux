# 与 SayAll 公开项目的功能对照

对照日期：2026-11-05。Remote Mic Linux 版本：0.3.0。

上游参考 [HD838A/remote-mic-app](https://github.com/HD838A/remote-mic-app)，固定对照提交 [03e96e92c9962acb8a7ef497db19089be46d97db](https://github.com/HD838A/remote-mic-app/tree/03e96e92c9962acb8a7ef497db19089be46d97db)。依据该提交的 README、TECHNICAL、COPYRIGHT、AppSettings、SettingsView、TranscriptHistorySection、MacroFeatureIntegration 和 PrivateFeatureIntegration。此表是代码/文档对照，不是对上游付费产品的实机验收。

上游是 macOS 应用，部分产品功能由可选私有模块提供。公开代码中有集成入口，不等于包含该功能全部实现。上游标为候选或待验收的能力，不能视为成熟功能；Linux 表内“未实现”和“未实测”也分别列出。

| 功能 | 上游公开资料中的状态 | Remote Mic Linux 0.3.0 | 差距 / 证据 |
| --- | --- | --- | --- |
| 小米遥控器音频接入 | ATVV 蓝牙语音、2 / 2 Pro | 部分硬件验证 | protocol.py / bridge.py；2 已测，2 Pro 待实物测试 |
| 单击、双击、长按 | 可视化配置、快捷键等 | 已实现 | actions.py / gestures.py / action_editor.py；语音键保留采音 |
| 自定义快捷键、左右修饰键 | 支持键盘选择及录制 | 已实现基础能力 | Linux evdev 键码与快捷键录制；没有上游完整键盘图形选择器 |
| 打开应用 | 自定义 App 与后续聚焦动作 | 部分实现 | 可选已安装 .desktop 应用；未做启动后聚焦指定输入框 |
| 聚焦前台输入框 | 公开入口及应用适配 | 未实现主动聚焦 | 我们保护用户已选目标，不能主动寻找/点击输入框 |
| 多套按键方案 | 候选功能，存在 SayAllButtonProfiles 可选组件 | 未实现 | 当前只有一套全局映射 |
| 按前台 App 自动切方案 | 候选/待实机验证 | 未实现 | 需独立配置及前台应用识别策略 |
| 组合动作 / 宏 | 候选功能，SayAllMacroRemoteMic 等可选模块 | 未实现 | 组合键不是多步骤宏；没有延迟、流程或动作库 |
| 系统虚拟麦克风 | MiRemoteV / BlackHole 路由 | Linux 对应能力 | PipeWire 音源，不主动替换默认输入/输出；外部工具仍需自身验证 |
| 第三方语音工具桥接 | 豆包、微信、Typeless 等工作流 | 部分实现 | 可设外部快捷键；Vokie 仅启动验证，未验证登录识别 |
| 内置语音转文字 | 私有 SayAllAI 集成入口，不能从公开入口推断全部实现 | 本项目独立实现 | 内置 SenseVoice 与有道服务，架构不同；不宣称复刻私有 AI |
| 最终文本输入 | macOS 注入与应用适配 | 已实现基础链路 | AT-SPI + X11 窗口校验、GTK 剪贴板、uinput；其他应用需实测 |
| 通知栏 / Dock | macOS 菜单栏与 Dock 设置 | 已实现 Linux 常驻 | tray.py、identity.py；关闭收起、状态菜单、单实例唤回 |
| 录音悬浮窗 | 上游有 HUD/私有 AI 展示入口 | 未实现独立悬浮窗 | 有应用内实时电平、预览、最终结果和通知栏录音图标 |
| 历史“回眸” | 默认关闭的候选能力，含应用/日期视图 | 未实现历史库 | 仅保留当前界面结果；不持久保存录音与识别历史 |
| 本地只读 MCP | 资料描述 stdio、客户端授权与撤销 | 未实现 | 需先设计可控历史存储，再做只读授权接口 |
| 使用统计 | 按日/周/全部、按键次数、语音时长等 | 未实现 | 仅运行日志和每段耗时 |
| 设备管理 | 多设备名称及设备卡片 | 基础实现 | 扫描与选择单个已配对设备；未做多设备档案 |
| Siri Remote / Chromecast | 独立可选模块/编译开关，部分会员相关 | 未实现 | 不能由图标造型推断 Apple 遥控器支持 |
| iPhone / Apple Watch / 网页输入 | 产品资料描述扩展入口，部分为独立/私有模块 | 未实现 | 当前仅本机蓝牙遥控器输入 |
| 常用语 | 产品会员功能 | 未实现 | 不包含会员、账号或付费体系 |
| 首次引导与权限检测 | macOS 引导、音频路由与测试 | 部分实现 | 运行诊断/错误日志；没有完整安装与权限向导 |
| 语言 | 中英及跟随系统 | 部分实现 | 当前中文界面；识别语言配置不等于 UI 国际化 |
| 登录启动 | macOS 启动行为设置 | 未实现 | --autostart 仅表示启动后连接，不是开机自启 |
| 自动更新 | Sparkle、自动/手动检查、预发布通道 | 未实现 | 提供 GitHub Releases AppImage 手动更新 |
| 分发 | macOS 安装、签名、公证 | Linux AppImage | 仅 Ubuntu 26.04 x86_64 预览包；不宣称跨发行版兼容 |

## 建议后续顺序

1. **优先完善日常输入与安装体验**：更多目标应用实测、2 Pro 实机、设备权限向导、断线恢复提示、登录自启选项。
2. **扩展按键工作流**：多配置、按应用切换、启动后聚焦输入框，再考虑组合宏。
3. **扩展长期使用能力**：用户明确选择后启用的历史库、统计、国际化、自动更新；MCP 应在存储与授权边界确定后设计。
4. **其他设备和跨设备输入**：分别研究协议并获得实物验证，不因为上游支持就标记 Linux 已支持。

本轮仅完成用户要求的 UI、常驻、打包、文档与现有识别修复，未擅自实现全部差异。应用原创图标独立于上游专有 Logo；来源链见 SOURCES.md。
